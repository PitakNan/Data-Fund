## 3. ความต่างจริง 18 เคส / 1.3 ลบ. มาจากอะไร

**ทั้ง 18 เคสเป็นเคสที่ Excel มีแต่ CSV ไม่มี** (ไม่มีเคสไหนที่ CSV มีแต่ Excel ไม่มีเลย)

| กลุ่ม | จำนวน | คำอธิบาย |
|---|--:|---|
| **ก) วันที่ส่งข้อมูลถูกแก้ภายหลัง** | 6 เคส | มีอยู่ใน CSV แต่วันที่ส่งข้อมูลเปลี่ยนไปเป็น พ.ค.–มิ.ย.69 จึงหลุดหน้าต่าง เช่น รพร.ปัว Excel ระบุ 3 มี.ค.69 → CSV ระบุ 27 พ.ค.69 (น่าจะเป็นการส่งข้อมูลซ้ำ/แก้ไขรายการ) |
| **ข) รายการอุปกรณ์เสริมล้วน 700 บาท** | 7 เคส | เป็นรายการ item 8701 อย่างเดียว (700 บาท) ที่ CSV ไม่ได้ส่งมาด้วย รวม 4,900 บาท |
| **ค) เคสเต็มที่หายไปจาก CSV** | 5 เคส | เคสจริงมูลค่า 9,000–53,000 บาท (แพร่ 2, มหาราช มช. 1, เชียงราย 1, นครพิงค์ 1) รวม ~219,250 บาท — **ยังอธิบายสาเหตุไม่ได้** |

**ส่วนต่างมูลค่า 1.3 ลบ. = 0.9 ลบ. (item เสริมในเคสที่ตรงกัน) + 0.4 ลบ. (18 เคสข้างต้น)**

### รายละเอียด 0.9 ลบ. — item เสริมที่ CSV ไม่ส่งมา
ในเคส 2,126 เคสที่ตรงกัน มี 1,293 เคสที่มูลค่าไม่ตรง **ทิศทางเดียวกันหมด 100% (CSV น้อยกว่าเสมอ)**

| Item Code | บาทที่ CSV ขาดไป |
|---|--:|
| **8701** | **896,492** |
| 8307 / 8705 | 5,000 / 1,250 |
| 5704C / 4701 / 8703 / 8602 | 600 / 600 / 190 / 150 |

ตัวอย่าง: Excel `[7005A 48,000][7401 2,000][8307 1,000][8701 700]` = 51,700 บาท
vs CSV `[7005A 48,000][7401 2,000]` = 50,000 บาท

## 5. ✅ ตรวจสอบฐานที่ใช้อยู่ตอนนี้ — ผลออกมาเหมือนกันทั้งสองวิธี

คำนวณ "ปีงบบริการ 2569, ตั้งแต่ 16 ก.ย.68 ถึง 25 มิ.ย.69" ด้วย 2 ฐานวันที่:

| ฐานวันที่ที่ใช้ | จำนวนเคส | มูลค่า |
|---|--:|--:|
| วันที่**ส่งข้อมูล** | 2,335 | 137,018,764 |
| วันที่**จำหน่าย** (ที่ dashboard ใช้อยู่) | 2,335 | 137,018,764 |

**ได้ผลเท่ากันเป๊ะทั้งสองวิธี** เพราะตัวกรองที่กำหนดชุดข้อมูลจริงคือ `ปีงบบริการ = 2569` ไม่ใช่ฟิลด์วันที่ —
ฟิลด์วันที่มีผลเฉพาะ**การจัดเคสเข้าเดือน**ในกราฟเทรนด์เท่านั้น

→ **ตัวเลขหัว KPI ปัจจุบัน (2,335 เคส / 137.0 ลบ.) ถูกต้องแล้ว และสอดคล้องกับข้อกำหนด "ใช้วันที่ส่งเบิก" ด้วย**
